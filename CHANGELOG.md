# Changelog

## [0.1.0](https://github.com/raphpion/bark/releases/tag/v0.1.0) (2026-10-28)

### Features

* **workspaces:** Arc-inspired Spaces with custom colors/emojis and two-way Chrome Tab Groups synchronization
* **pinned-tabs:** pinned tabs with nested collapsible folders, drag-and-drop ordering, and live navigation tracking with "Back to Pinned URL"
* **command-palette:** standalone popup window (`Alt+T` / `Ctrl+T`) with instant tab search, space switching, and custom search engines (e.g. `yt`, `gh`)
* **hub:** Bark Hub manager for Spaces visual board, Tab Archive search, and Downloads tray
* **clean-url:** copy share URL shortcut (`Alt+C` / `Ctrl+C`) automatically stripping tracking parameters (`utm_*`, `fbclid`, `gclid`, etc.) with feedback toast
* **security:** hardened Manifest V3 architecture, ephemeral service worker state resilience, sender verification, and Preact TSX rendering with zero `innerHTML`
